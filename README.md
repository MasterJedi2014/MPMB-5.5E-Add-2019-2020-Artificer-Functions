# MPMB-5.5E-Add-2019-2020-Artificer-Functions
This script returns the 2019/2020 functions of the Lvl 1 "Tinker's Magic" &amp; Lvl 14 "Magic Item Savant" Artificer class features to the 2024 Artificer. This script exists for those characters and/or tables that require or otherwise wish to reinstate these functions to the class.

**This script is to be used in conjunction with the *Eberron: Forge of the Artificer* (EFotA) script by ThePokésimmer, specifically the 5.5E (v24) version of the script. You can find that script here: https://github.com/thepokesimmer/2024-PHB/blob/main/pub_20251209_EFotAv24.js This script will not work properly without the aforementioned script installed first, and is already a part of the 5E version of the aforementioned script.**

**Functionality Restored:**
- *Tinker's Magic:*
  - As a Magic action, I can alternatively use my Tinker's Magic to give 1 property to a nonmagical Tiny object:
    - Emit light (5-ft radius bright light, equal dim), an odor, or a nonverbal sound
    - Static visual effect on one surface, or emit a 6-second recorded message when tapped
  - If I instill a property in more objects than I can have active, the oldest loses its property
  - Each Tiny object I infuse with semi-permanent magic removes a usage from the maximum number of items I can temporarily produce via the Tinker's Magic rules from EFotA.

- *Magic Item Savant:* (Now under Advanced Artifice)
  - I additionally ignore all Class, Species, Spell, and Level requirements on attuning to or using a magic item
